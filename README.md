# BuildPC

Configurador visual inicial para el montaje gaming del usuario.

## Verlo
Abre `index.html` localmente o activa GitHub Pages desde **Settings → Pages → Deploy from a branch → main → /(root)**. Después estará disponible en:

`https://wizzadrds.github.io/buildpc/`

## Qué incluye
- Vista conceptual 3D/CSS de una torre de cristal negra con iluminación ARGB.
- Selectores para caja, CPU, GPU, RAM, refrigeración, ventiladores, fuente y color RGB.
- Resumen copiable de la configuración.
- Diseño adaptable a móvil y escritorio.

## Limitaciones importantes
Esta primera versión es una maqueta visual interactiva, no el configurador oficial de BuildCores. No llama a una API de BuildCores, no comprueba compatibilidad, dimensiones, consumo ni conectores, y los componentes 3D son ilustrativos.

Antes de comprar:
- Confirmar el modelo exacto de la refrigeración líquida actual.
- Confirmar marca y modelo de la fuente de 750 W.
- Mantener como placa real la MSI B450-A PRO MAX (no la B450 Tomahawk MAX).
- Confirmar el espacio real para radiador y ventiladores en la caja elegida.
- La RTX 5060 Ti seleccionada debe ser la versión de 16 GB.

## Publicación
En GitHub: **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root)**.
